# Learn Python

These lessons are copied from **[Python Programming for Biologists](https://github.com/burkesquires/python_biologist)** by R. Burke Squires (lessons 03–06 only, copied November 2026). All credit for these materials goes to the original author; check the original repo for updates and later lessons.

Work through the folders in order. Each folder has slides (`.pptx`/`.pdf`) and Jupyter notebooks (`.ipynb`). You don't need to install anything: click a **Open in Colab** badge below to run a notebook in your browser (works on a Chromebook). See [Opening notebooks in Google Colab](../README.md#opening-the-learn-python-notebooks-in-google-colab) in the main README for details.

| Folder | Topic |
|---|---|
| `03_intro_programming` | Basic programming concepts (no Python experience needed) |
| `04_python_programming` | Python language fundamentals |
| `05_python_data_analysis` | Working with data using NumPy and pandas |
| `06_data_vis_python` | Making plots and data visualizations |
