### Week 1: Background reading

Read the de novo protein design review paper: `readings/Baker_review_2026.pdf`

Begin exploring the [RFdiffusion documentation](https://github.com/RosettaCommons/RFdiffusion). For now I want to get a sense of how comfortable you might be using a tool like this - it's totally okay if you've never seen anything like this, and need a lot of coding instruction before we get started.

Questions to think about as you read (we will discuss next week):

1. What does “de novo” mean here, and how is it different from engineering a protein that already exists?

2. The authors say designing structures, assemblies, and binders is “close to being solved,” but enzymes and switches are not. What’s different about an enzyme that makes it harder than a binder?

3. AlphaFold predicts structure from sequence. Design tools go the other direction. Why are structure prediction models be useful for a design problem?

4. The review claims designed proteins will have functions “beyond what natural evolution produced.” How is this possible?

5. If you could design any protein and it would definitely work, what would you make and why? Then: what would you need to measure to know it worked?
