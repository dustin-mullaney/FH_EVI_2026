# Week 2-3: Background reading - protein language models

Read the ESMC and EVO2 papers: [`readings/ESMC.pdf`](readings/ESMC.pdf) and https://www.nature.com/articles/s41586-026-10176-5 (EVO2 file is too big for github, email me if you can't access)

Questions to think about as you read:

1. How do these models differ from the models discussed in last week's review paper? (hint: look at the next question)

2. How is possible for these models to "learn" protein structure without being trained on any structural data?

3. Are protein sequences generated by these models "de novo" in the same way that proteins designed by models like RFdiffusion?

4. When might these models be better than RFdiffusion for protein design?
